# Telegram-бот для генерации видео и автопостинга

Этот проект представляет собой Telegram-бота, который позволяет пользователю на основе введённой темы генерировать короткие видео с аватаром и публиковать их в социальные сети.

## Структура проекта

- `backend/`: FastAPI приложение для обработки логики генерации видео.
- `bot/`: Код Telegram-бота.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL репозитория>
cd <название папки>
```

### 2. Настройка окружения

В проекте используется два файла окружения: один для бэкенда, другой для бота.

- Переименуйте `backend/example.env` в `backend/.env` и укажите свои данные для подключения к базе данных.
- Переименуйте `bot/example.env` в `bot/.env` и укажите свой токен для Telegram-бота.

### 3. Установка зависимостей

**Бэкенд:**
```bash
pip install -r backend/requirements.txt
```

**Бот:**
```bash
pip install -r bot/requirements.txt
```

### 4. Запуск

**Бэкенд:**
```bash
uvicorn backend.app.main:app --reload
```

**Бот:**
```bash
python bot/bot.py
```

### 5. Мониторинг задач (Flower)

Для отслеживания состояния задач Celery, используйте Flower:

```bash
celery -A app.core.celery_app flower --port=5555
```
Это нужно запускать из папки `backend`.
